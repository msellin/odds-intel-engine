G2 — mobile fixes (375px)
-------------------------
1. CLV per-match table (predictions-record/clv) used overflow-y-auto
   only with a `truncate` Match cell inside a non-fixed-layout table.
   On 375px team names wrapped messily and the cell flexed wider than
   the viewport. Switched wrapper to `overflow-auto`, added `min-w-[420px]`
   to the table, and replaced `truncate` with `whitespace-nowrap` so the
   table cleanly horizontal-scrolls instead of busting the page width.

2. Leaderboard 7-col table (predictions-record/leaderboard) added
   `min-w-[560px]` and `whitespace-nowrap` on numeric column headers
   so labels stay legible and the table scrolls horizontally on phones
   instead of compressing "Hit-rate" / "Log-loss" into illegible columns.

3. WC home-page inline leaderboard row (`LeaderboardInlineRow`) — long
   display names were free to expand the Player <td> and push the
   right-aligned Total off-screen on 375px. Added `min-w-0` to the cell
   + inner flex container and `truncate` + `shrink-0` on the AI/you
   chips so long names truncate cleanly.

4. Bonus: WC activity tiles — added `min-w-0` to the inner flex so the
   `truncate` on the label actually engages (parent was a flex without
   min-w-0, so the truncate never activated).

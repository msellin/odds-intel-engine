## The bigger problem: 170 WEAKEN

These assert only that a string still appears in a source file. They pass
whether or not the code works, and keep passing after it is deleted — which is
why the suite reports 685 green while whole products are dead. Converting even
the top 20 to behavioural assertions is worth more than fixing all 22 failures.

Do not bulk-rewrite. Take them in domain batches, and only where a real
behavioural assertion is possible.

## Rules for this cleanup

1. Never delete a test on a name match. Require production-liveness evidence.
2. Never change production code to make a test pass — especially COOLBET-MAC-DAEMON.
3. One domain per commit, so any batch is revertible.
4. Re-run the audit after each batch and update the counts above from its output.
